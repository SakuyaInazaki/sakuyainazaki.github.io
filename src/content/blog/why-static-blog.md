> "Hyperlinks are the true synapses of the open web."

现在的互联网，似乎已经被各种大厂的封闭平台瓜分完毕。每个人都在发朋友圈、发动态、刷短视频，但所有的内容都被囚禁在各自的应用孤岛里，离开那个平台就什么都不是。

### 为什么还要自己折腾个人主页？

- **真正的数据所有权**：你的每一篇文章都是本地电脑里的一个 Markdown 文本文件，不受任何平台审核、限流或关服的影响。
- **免运维的松弛感**：纯静态网站部署在 GitHub Pages 上，没有数据库崩溃的隐患，没有服务器到期断费的焦虑，全球 CDN 免费分发。
- **友链（Webring）的温度**：
  在 Web 1.0 时代，独立博客之间最迷人的地方就是**互加友链**。你顺着一个人的博客导航，点进他同学或朋友的主页，发现了一个完全不同但同样有趣的精神世界。

如果你也有独立博客或个人页面，欢迎在我的 `/friends/` 板块随时与我交换友链！
