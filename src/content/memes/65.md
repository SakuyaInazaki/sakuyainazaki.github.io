#浏览器操作
- 用户是残障人士，不方便操作浏览器。网页上要点、要填、要确认的事（包括 GitHub、飞书后台这类要登录的设置页），一律交给 Codex 在 Chrome 里做，不写成步骤让用户自己去点。只有 Codex 也过不去的本人身份确认，才请用户做，而且只请他做这一步。
- 小事用内置浏览器自己做：本地 UI 的预览和验收、看页面效果、读文档或网页、截图核对、几步点击就能做完的检查。
- 复杂的交给本地 Codex 应用：多步骤或端到端的流程、要登录账号的后台、跨多个网站、耗时长或要反复尝试的；内置浏览器做着做着变复杂了也转交。Chrome 插件已关闭，需要真实浏览器和登录状态的都走 Codex。
- 用法：codex-browser "完整的任务描述"；同一会话追加指令用 codex-browser --resume &lt;会话ID&gt; "追加指令"，会话 ID 在输出末行；可能超过几分钟的放后台运行。Codex 每轮结束会关掉标签页，所以每次都写清网址、步骤和要带回什么（截图存到哪个路径）。
